# Former Arch Derivative PKGBUILDS for Xlibre

This repository used to provide PKBUILD files for building Xlibre packages on Arch Linux derivative distributions and Arch Linux itself. It has been archived in favor of [https://github.com/xlibre-arch](https://github.com/xlibre-arch). Please see the website at [https://xlibre-arch.github.io](https://xlibre-arch.github.io/) for an overview.
